The Files can be summarised by the Chapters of the dissertation as follows: 

M4A Combination: Mainly a mixture of code for the different chapter that produces figures for the paper

**Chapter 3 (Simulations) ** <br />
1 Gumbel: All simulations for the Gumbel domain of attraction <br />
2 Frechet: All simulations for the Fr\'echet domain of attraction <br />
3 Weibull: All simulations for the Weibull domain of attraction <br />

**Chapter 4 (Red Sea) ** <br />
Red Sea: Simulations for the monthly, weekly step function <br />
Red Sea Wave: Simulations for the smooth harmonic model fitted to the Red Sea data <br />

**Chapter 5 (Missing Data) ** <br />
Red Sea Missingness: Simulations for missing data on the Red Sea simulations <br />
