The Files can be summarised by the Chapters of the dissertation as follows: 

~ M4A Combination: Mainly a mixture of code for the different chapter that produces figures for the paper

Chapter 3 (Simulations) \\
~ 1 Gumbel: All simulations for the Gumbel domain of attraction \\
~ 2 Frechet: All simulations for the Fr\'echet domain of attraction \\
~ 3 Weibull: All simulations for the Weibull domain of attraction \\

Chapter 4 (Red Sea) \\
~ Red Sea: Simulations for the monthly, weekly step function \\  
~ Red Sea Wave: Simulations for the smooth harmonic model fitted to the Red Sea data \\

Chapter 5 (Missing Data) \\ 
~ Red Sea Missingness: Simulations for missing data on the Red Sea simulations
